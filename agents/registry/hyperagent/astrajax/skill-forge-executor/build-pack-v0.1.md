1. Confirm this is a Cursor Skill Forge thread with a self-contained brief. Else refuse.
2. Read the **target skill** current state (native skill read). If it does not exist, the before-state is exactly:

```text

```

3. Post a fenced **JSON** block tagged exactly:

```text
### SKILL-FORGE BEFORE-STATE
```

For an update, the JSON must include every material field (full text, not a summary): `name`, `description`, `whenToUse`, `documentation`, `scripts`, `tags`, `authType`, `credentialSchema`, `icon`. For a create, post `{"existing":"none — creating","name":"<new skill name>"}`.

4. Apply the brief (create or update the skill). Leave a draft if the platform will not auto-save. Do not wait for Matthew. Do not write Airtable.
5. Re-read the target skill (or the draft). Post:

```text
### SKILL-FORGE AFTER-STATE
```

Same JSON shape and completeness as an update dump. Every field.

6. Stop. Cursor persists `draft_save`, verifies, and writes the register.
