# Retired build generators

These scripts generated the **Intake → Curator → Scanner → Publisher** Hyperagent
lane and their Cursor mirrors. That lane was retired in favour of **Clive's Man**
(Cursor-native) on 2026-06-24.

**Do not run these for new work.** They remain so you can regenerate historical
exports or audit what an old version contained.

## Contents

| Script | Was |
|--------|-----|
| `build_clive_intake_v1_*.py` | Clive Intake |
| `build_clive_curator_v*.py` | Clive Curator (v0.1–v5) |
| `build_clive_context_scanner_v0_*.py` | Clive Context Scanner |
| `build_clive_publisher_v0_2.py` | Clive Publisher |
| `build_clive_agent_factory_v2.py` | Superseded by `../build_clive_agent_factory_v3.py` |
